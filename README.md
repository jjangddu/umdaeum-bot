# 엄대엄 봇

롤 내전 밸런스 매칭 디스코드 봇

## 특징

- **2026 봄 SOOP 멸망전 점수표 기준** 밸런스 매칭
  - 포지션별 차등 점수 적용 (탑/정글/미드/원딜/서포터)
  - 마스터 이상은 LP 구간별 세분화
- **내전 자체 ELO 시스템**
  - 내전이 진행될수록 승패에 따라 개인 점수가 변동됨
  - 초기에는 솔랭 기준, 판수가 쌓이면 내전 ELO 비중 증가 (최대 50%)
  - 관리자 수동 보정 가능
- **최적 밸런스 탐색** - 모든 조합을 탐색하여 점수 차이가 가장 작은 팀 구성
- **파티 시스템** - 같은 PC방 등 같은 팀 배정
- **게스트 참가** - 디스코드 미가입자도 닉네임으로 참가 가능
- **빠른내전** - 음성채널에 있는 사람들로 바로 팀짜기
- **관리자 도구** - 유저 선택 드롭다운으로 간편하게 추가/제거

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/등록 [이름] [태그]` | 롤 닉네임 등록 |
| `/대리등록 [멤버] [이름] [태그]` | [관리자] 다른 유저 대리 등록 |
| `/갱신` | 소환사 정보 최신 갱신 |
| `/프로필 [멤버]` | 프로필 조회 |
| `/포지션 [1순위] [2순위]` | 선호 포지션 등록 |
| `/내전` | 내전 모집 시작 |
| `/빠른내전` | 음성채널 사람들로 바로 팀짜기 |
| `/코인토스` | 블루/레드 사이드 랜덤 결정 |
| `/결과등록 [매치ID] [승리팀]` | 내전 결과 기록 |
| `/내전전적 [멤버]` | 내전 전적 확인 |
| `/최근내전` | 최근 내전 기록 |
| `/elo보정 [멤버] [elo]` | [관리자] 내전 ELO 수동 보정 |

## 내전 진행 흐름

### 일반 모드
1. `/내전` → 로비 생성
2. 참가 버튼 → 포지션 선택 (언랭은 예상 티어 선택)
3. 팀 짜기 → 최적 밸런스 자동 매칭
4. 코인 토스 → 블루/레드 사이드 결정
5. 게임 후 → 블루팀 승리 / 레드팀 승리 버튼으로 결과 기록
6. 한판 더 / 내전 종료

### 빠른내전 모드
1. 음성채널에 모이기
2. `/빠른내전` → 자동 참가 + 바로 팀짜기

### 로비 버튼

**1행 (일반):** ✋ 참가 | 🚪 나가기 | 🔗 파티 묶기 | ⚔️ 팀 짜기

**2행 (관리자):** ➕ 추가 | ➖ 제거 | 🔊 음성채널 전체참가 | 👤 게스트추가

## 설치 및 실행

```bash
# 레포 클론
git clone https://github.com/jjangddu/umdaeum-bot.git
cd umdaeum-bot

# .env 파일 생성
cp .env.example .env
# DISCORD_TOKEN, RIOT_API_KEY 입력

# 가상환경 생성 및 의존성 설치
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 봇 실행
python bot.py
```

## 디스코드 봇 설정

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 봇 생성
2. Bot 탭 → Privileged Gateway Intents 3개 모두 ON
3. OAuth2 → bot + applications.commands 스코프로 초대 링크 생성
